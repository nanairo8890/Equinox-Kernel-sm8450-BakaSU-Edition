# Equinox BakaSU Edition 2.5

Equinox Kernel by **[LF52406](https://github.com/LF52406)** for the POCO F5 Pro / Redmi K60 (`mondrian`),
BakaSU edition by **Nanairo8890** with LF52406's permission

NoMount goes to **v2.3.0**. BakaSU (548d1dda) and SUSFS (v2.4.0) are the same as in 2.0.1

## Files

- `Equinox-5.10.269-BakaSU-2.5-mondrian.zip`: AnyKernel3 zip. Flash it from a recovery or a kernel
  flasher; it checks the ROM's vendor modules and then replaces only the kernel `Image`, keeping the
  ROM's ramdisk, header and bootconfig
- `Equinox-5.10.269-BakaSU-2.5-mondrian-checkonly.zip`: the same package, named so that it only runs
  the check and flashes nothing. Use it to find out whether your ROM is compatible
- `BakaSU_v4.2.0-rc3_35257-arm64-v8a-release.apk`: the official BakaSU manager, from BakaSU's CI
- `CHANGELOG.en.txt`, `CHANGELOG.es.txt`, `CHANGELOG.pt-BR.txt`, `CHANGELOG.ru.txt`: full changelog

## Before flashing

- Back up your `boot` partition first
- If you update your ROM, flash the zip again afterwards, because the ROM ships its own kernel
- Update the NoMount metamodule to v2.3.0 from its official release: NoMount asks for the driver and the
  metamodule to be updated together
- 2.5 keeps the same BakaSU 35257 manager as 2.0.1

## What 2.5 adds

- **NoMount `v2.3.0`** built in (`7914458`, driver version 23), up from `v2.2.0`: rules follow the file's
  inode instead of the path text, redirected files open faster, memory fixes (an out-of-bounds read and
  use-after-free cases), security fixes (LSM checks on xattr changes, SUID/SGID bits cleared on virtual
  inodes), fixes for crashes with FUSE mounts and cgroup2, and faster rule loading at boot. This
  edition's changes are kept: apps whose modules are umounted see the stock filesystem, and NoMount stays
  hidden from `/sys/module` and `/proc/kallsyms`
- **Why the kernel is updated**: the v2.3.0 metamodule also works with an older driver (22 or newer), so updating the
  kernel is not required to run it, but the fixes above live in the kernel driver, so only an updated kernel gets
  them, and NoMount asks to update the driver and the metamodule together
- **If NoMount shows "Bootloop Prevented"**, it disabled itself after a boot that did not finish (for example when a
  kernel is tested without flashing it): delete the `disable` file in `/data/adb/nomount/` and reboot, or install the
  NoMount module again
- Same BakaSU `548d1dda` (BakaSU has published nothing newer), SUSFS v2.4.0, the hiding of KernelSU's
  SELinux types from 2.0.1, BBR, DroidSpaces, `/proc/kallsyms` filter and installer

## Compatible ROMs

2.5 exports the same symbol CRCs as 2.0 and 2.0.1, so the same ROMs are compatible:

- **Compatible:** MistOS 5.1 Beta (20261011 to 20261025) and MistOS 5.0 Alpha 20260914; the latest builds
  from Keosh with the kernel `5.10.269-gki-g1598dc02ea84`: crDroid 12.12 (20260928), Evolution X 11.11,
  Infinity-X 3.12 (VANILLA, GAPPS core and extra), Lunaris 3.12 (VANILLA and GMS), LineageOS 23.2
  (20260929) and Axion 2.8 (VANILLA and GMS); Infinity-X 4.1 by LF5 (17.10.2026); crDroid 12.12 by Taha
  Keles (20260930)
- **Not compatible:** AOSPA calcite and PenguinOS celerity. They use their own kernel
  (`5.10.269-beryl-7156c6f9fb`) and the installer stops on them

## Checks

- This BakaSU edition was not booted on a phone for this version; the NoMount driver is the same code that was tested with the FinaSU edition (NoMount 23 (720), the module rules injected and the boot finishing safely), and BakaSU itself is unchanged from 2.0.1
- KMI against clean Equinox: 0 changed CRCs and 0 removed symbols (only `put_pid_ns` is added)
- Vendor module CRCs match (337 from `vendor_boot` and 390 from `vendor_dlkm`) for MistOS 5.1 Beta 20261025 and for the 11 latest Keosh builds; AOSPA and PenguinOS are still not compatible
- Infinity-X 4.1 was not rechecked in this version because its modules are no longer on the build machine
- The `/proc/kallsyms` filter was checked on the built kernel: none of the driver symbols left visible reveals root, and NoMount adds no new visible symbol
