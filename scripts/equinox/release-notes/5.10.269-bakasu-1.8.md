# Equinox BakaSU Edition 1.8

Equinox Kernel by **[LF52406](https://github.com/LF52406)** for the POCO F5 Pro / Redmi K60 (`mondrian`),
BakaSU edition by **Nanairo8890** with LF52406's permission.

First release of the BakaSU edition: the kernel of the
[Equinox FinaSU Edition 1.8](https://github.com/nanairo8890/Equinox-Kernel-sm8450-FinaSU-Edition) with
**BakaSU** instead of FinaSU as the root driver. SUSFS, NoMount, DroidSpaces, BBR and the installer, which
checks the ROM's vendor modules before flashing, are the same.

## Files

- `Equinox-5.10.269-BakaSU-1.8-mondrian.zip`: AnyKernel3 zip. Flash it from a recovery or a kernel
  flasher; it checks the ROM's vendor modules and then replaces only the kernel `Image`, keeping the
  ROM's ramdisk, header and bootconfig.
- `Equinox-5.10.269-BakaSU-1.8-mondrian-checkonly.zip`: the same package, named so that it only runs
  the check and flashes nothing. Use it to find out whether your ROM is compatible.
- `BakaSU_v4.2.0-rc3_35257-arm64-v8a-release.apk`: the BakaSU manager (`com.resukisu.resukisu`), built by
  BakaSU's CI from the same commit as the kernel's BakaSU. It updates earlier BakaSU managers in place.
- `CHANGELOG.en.txt`, `CHANGELOG.es.txt`, `CHANGELOG.pt-BR.txt`, `CHANGELOG.ru.txt`: full changelog.

## Before flashing

- Back up your `boot` partition first.
- If you update your ROM, flash the zip again afterwards, because the ROM ships its own kernel.
- Install the BakaSU manager 35257 from this release (or a newer one) and let it update `ksud`. This
  kernel uses UAPI 6.
- To mount modules with NoMount, install the official NoMount metamodule (v2.2.0 or newer): it detects
  the built-in driver and does not load its own module.

## What 1.8 has

- **BakaSU** `main` at `516d3e87` (`v4.2.0-rc3-86`, version 35257), built in, with BakaSU's **SUSFS Inline
  Hook** method, the one BakaSU uses on kernels patched with SUSFS. BakaSU's module preinit is built in.
- **SUSFS `eb95da0`** (v2.3.0), through BakaSU's SUSFS support. SUSFS's priority filter
  (`set_priority_uid_filter`, "Hide third party apps" in BRENE) has no effect, because BakaSU does not
  dispatch that command.
- **NoMount `v2.2.0`** by maxsteeel built in, with deref3046's fix and the edition's three changes: apps
  whose modules BakaSU/SUSFS unmount see the original system, no `/sys/module/nomount/version`, and
  NoMount's symbols hidden from `/proc/kallsyms`.
- **`/proc/kallsyms` hiding**: the filter of the FinaSU edition 1.8, plus BakaSU's own symbols that FinaSU does not have: `is_manager`,
  `kernel_patch_type`, `manage_try_umount`, the `do_get_managers`, `do_get_hook_type`, `do_dynamic_manager` and
  `do_get_kernel_patch_implement` supercall handlers, `disable_seccomp`, `has_v1_signature_file`,
  `detect_conflict_thread`, `kAdbd` and the `block_modules` parameter string. Each added prefix was checked
  against a clean Equinox build and against the vendor modules of MistOS 20261025 and Infinity-X 4.1.
- **The installer's vendor module check** (`kmicheck`) and the **`checkonly`** package, as in the FinaSU
  edition.
- DroidSpaces, BBR by default, AOSP Clang r584948 with ThinLTO, Clang CFI and MODVERSIONS, as in the
  FinaSU edition.

## If you use BRENE

- Do not configure SUSFS from the BakaSU manager while you use BRENE: both write the same settings.
- BRENE applies `su_compat`, `kernel_umount` and `selinux_hide` on every boot; change them from its WebUI.
- A `uname -r` with a double hyphen (`5.10.269--N-g...`) comes from BRENE's uname spoofing, which cannot
  find a KMI value in this kernel. Set a custom uname in BRENE.

## Compatible ROMs

This kernel exports exactly the same symbol CRCs as the FinaSU edition 1.8, so the same ROMs are compatible:

- **Compatible:** MistOS 5.1 Beta (20261011 to 20261025) and MistOS 5.0 Alpha 20260914; the latest builds from Keosh with the kernel
  `5.10.269-gki-g1598dc02ea84`: crDroid 12.12 (20260928), Evolution X 11.11, Infinity-X 3.12 (VANILLA,
  GAPPS core and extra), Lunaris 3.12 (VANILLA and GMS), LineageOS 23.2 (20260929) and Axion 2.8 (VANILLA
  and GMS); Infinity-X 4.1 by LF5 (17.10.2026); crDroid 12.12 by Taha Keles (20260930).
- **Not compatible:** AOSPA calcite and PenguinOS celerity. They use their own kernel
  (`5.10.269-beryl-7156c6f9fb`) and the installer stops on them.

## Checks

- KMI against clean Equinox: 0 changed CRCs and 0 removed symbols (only `put_pid_ns` is added); the exports
  (`vmlinux.symvers`, 14610) are identical to the FinaSU edition 1.8.
- Vendor module CRCs match MistOS 5.1 Beta 20261025 (the same modules as 20261024 and 20261023),
  Project Infinity-X 4.1, MistOS 5.0 Alpha 20260914 and the Keosh builds above (337 `vendor_boot` and
  390 `vendor_dlkm` modules each).
- Build: BakaSU 35257 with SUSFS Inline hooks (all seven SUSFS hooks found) and SUSFS's SELinux-hiding
  hook, SUSFS v2.3.0, and the module preinit runner built in.
- **Tested on the phone** (POCO F5 Pro, MistOS 5.1 Beta 20261025) by booting this `Image` with
  `fastboot boot`, without flashing it: boots, 385 modules loaded and 0 rejected, root works, SELinux
  Enforcing, no panics or warnings, BakaSU 35257 built in (UAPI 6), NoMount loaded (`nm version` 22), SUSFS
  v2.3.0 with its 9 features, BBR, and `/proc/kallsyms` shows none of the root-revealing names. The BakaSU
  manager app was not installed on the test phone, so the manager itself was not tried with this kernel.
