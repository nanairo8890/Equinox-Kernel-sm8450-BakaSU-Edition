# Equinox BakaSU Edition 2.5.2

Equinox Kernel by **[LF52406](https://github.com/LF52406)** for the POCO F5 Pro / Redmi K60 (`mondrian`),
BakaSU edition by **Nanairo8890** with LF52406's permission

NoMount goes to **v2.3.1**. BakaSU, SUSFS, the installer and everything else are the same as 2.5.1

## Files

- `Equinox-5.10.269-BakaSU-2.5.2-mondrian.zip`: AnyKernel3 zip. Flash it from a recovery or a kernel
  flasher; it checks the ROM's vendor modules and then replaces only the kernel `Image`, keeping the
  ROM's ramdisk, header and bootconfig
- `Equinox-5.10.269-BakaSU-2.5.2-mondrian-checkonly.zip`: the same package, named so that it only runs
  the check and flashes nothing. Use it to find out whether your ROM is compatible
- `BakaSU_v4.2.0-rc3_35261-arm64-v8a-release.apk`: the official BakaSU manager, from BakaSU's CI
- `CHANGELOG.en.txt`, `CHANGELOG.es.txt`, `CHANGELOG.pt-BR.txt`, `CHANGELOG.ru.txt`: full changelog

## Before flashing

- Back up your `boot` partition first
- If you update your ROM, flash the zip again afterwards, because the ROM ships its own kernel
- Install the BakaSU 35261 manager from this release
- Update the NoMount metamodule to v2.3.1 from its official release: NoMount asks for the driver and the
  metamodule to be updated together

## What 2.5.2 adds

- **NoMount `v2.3.1`** (`dcd77d0`, driver version 23, count 785), up from `v2.3.0`. The wire protocol is still v23
- Kernel fixes from upstream: a hot-path and lifetime pass, larger hash tables for rules and UIDs, file handle export
  operations for redirected files, and superblock cleanup moved to `put_super`
- Update the NoMount metamodule to v2.3.1 too: it works with the 2.3.0 driver and the other way round, but upstream recommends updating both together
- Same BakaSU `5d6d1843`, SUSFS v2.4.0, BBR, DroidSpaces, `/proc/kallsyms` filter and installer

## Compatible ROMs

2.5.2 exports the same symbol CRCs as 2.0 and 2.0.1, so the same ROMs are compatible:

- **Compatible:** MistOS 5.1 Beta (20261011 to 20261025) and MistOS 5.0 Alpha 20260914; the latest builds
  from Keosh with the kernel `5.10.269-gki-g1598dc02ea84`: crDroid 12.12 (20260928), Evolution X 11.11,
  Infinity-X 3.12 (VANILLA, GAPPS core and extra), Lunaris 3.12 (VANILLA and GMS), LineageOS 23.2
  (20260929) and Axion 2.8 (VANILLA and GMS); Infinity-X 4.1 by LF5 (17.10.2026); crDroid 12.12 by Taha
  Keles (20260930)
- **Not compatible:** AOSPA calcite and PenguinOS celerity. They use their own kernel
  (`5.10.269-beryl-7156c6f9fb`) and the installer stops on them

## Checks

- Tested on the phone (POCO F5 Pro, MistOS 5.1 Beta 20261025) with one boot from `fastboot boot`, nothing flashed: 385 modules load, SELinux is Enforcing, root works, `nm version` reports 23 (785), NoMount loads, SUSFS v2.4.0 is initialized, `dmesg` shows no Oops or panic, and `/proc/kallsyms` shows none of the root-revealing names
- KMI against clean Equinox: 0 changed CRCs and 0 removed symbols (only `put_pid_ns` is added)
- Vendor module CRCs match (337 from `vendor_boot` and 390 from `vendor_dlkm`) for MistOS 5.1 Beta 20261025 and for the 11 latest Keosh builds; AOSPA and PenguinOS are still not compatible
- The build shows no warnings or errors in the BakaSU, SUSFS and NoMount code
- Infinity-X 4.1 was not rechecked in this version because its modules are no longer on the build machine
- The `/proc/kallsyms` filter was checked on the built kernel: none of the driver symbols left visible reveals root, and NoMount adds no new visible symbol
